# Accès direct au jeu

Après le premier déploiement, le jeu sera accessible à l’adresse :

https://warkishi.github.io/valhala-projectc/

Le premier build peut prendre quelques minutes.

Dans le dépôt, vérifiez ensuite :

- Settings > Pages
- Source : GitHub Actions

Si le dépôt est privé, GitHub Pages doit être activé avec un paramétrage compatible au niveau du plan et du dépôt ; dans la plupart des cas, la publication publique est la plus simple pour un accès direct.
