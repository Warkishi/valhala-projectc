# Valhala Projectc

Ce dépôt contient une version web compatible GitHub Pages du prototype Valhala Projectc.

## Fonctionnalités

- système de gacha avec 10 raretés
- probabilités exponentielles
- inventaire de héros
- sauvegarde automatique dans le navigateur
- déploiement GitHub Pages prêt à l'emploi

## Lancer localement

Ouvrez simplement le fichier `index.html` dans votre navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
